## How to deploy the files:

From this directory:
```shell
ln -f -s -n "$PWD/GEMINI.md" "$HOME/.gemini"
ln -f -s -n "$PWD/cli/settings.json" "$HOME/.gemini/antigravity-cli"
ln -f -s -n "$PWD/ide/settings.json" "$HOME/Library/Application Support/Antigravity IDE/User"
```
